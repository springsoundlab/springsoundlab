// 02 — О студии

Построено для перфекционистов

NeonWave Studio — это 800 м² профессионального пространства в центре Москвы. Три live-зала, два control-room'а и репетиционное пространство.

  • ✓Звукоизоляция Floyd Rose — NRC 0.95, полная акустическая независимость залов
  • ✓Аналоговый тракт Neve + SSL с прямым подключением к Pro Tools HDX 32-bit / 192kHz
  • ✓Зал для живых оркестров до 24 музыкантов с панорамным окном
  • ✓Dolby Atmos сертифицированный мониторинг — 9.1.6 speaker setup
  • ✓Лицензированные сэмпл-библиотеки Spitfire, Native Instruments, Output
  • ✓Комната отдыха для артистов, кухня, лаунж-зона 24/7
